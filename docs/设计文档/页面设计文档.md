# 团队知识库管理工具 - 页面设计文档

## 1. 设计概述

### 1.1 设计目标
- **简洁明了**: 界面简洁，操作直观，降低学习成本
- **功能聚焦**: 突出核心功能，避免界面冗余
- **响应式设计**: 兼容桌面和平板设备
- **一致性**: 保持设计风格和交互模式一致

### 1.2 设计规范
- **UI框架**: Ant Design 5.x
- **色彩主题**: 蓝色系主色调 (#1890ff)
- **字体**: 系统默认字体栈
- **图标**: Ant Design Icons
- **布局**: 经典的左侧导航 + 主内容区域

### 1.3 用户角色
- **管理员**: 可访问所有功能和页面
- **编辑者**: 可上传、编辑文档，管理自己的文档
- **查看者**: 只能查看有权限的文档

## 2. 整体布局设计

### 2.1 主框架布局

```
┌─────────────────────────────────────────────────────────────┐
│                    顶部导航栏 (Header)                        │
│  Logo | 搜索框 | 用户信息 | 退出                              │

│                 │                                           │

│                 │                                           │
│  - 文档管理      │                                           │
│  - 标签管理      │                                           │
│  - 用户管理      │                                           │
│                 │                                           │
└─────────────────┴───────────────────────────────────────────┘
```

### 2.2 响应式布局
- **桌面端 (≥1200px)**: 左侧导航固定显示
- **平板端 (768px-1199px)**: 左侧导航可收缩

## 4. 组件设计

### 4.1 通用组件

#### 4.1.1 搜索框组件 (SearchBox)
- 支持关键词搜索
- 搜索历史提示
- 清空搜索功能

#### 4.1.2 标签选择器 (TagSelector)
- 下拉多选标签
- 支持新建标签
- 颜色显示

#### 4.1.3 文件上传器 (FileUploader)
- 拖拽上传支持
- 文件类型验证
- 上传进度显示
- 文件预览

#### 4.1.4 权限控制组件 (PermissionControl)
- 基于用户角色显示/隐藏内容
- 操作权限验证

### 4.2 业务组件

#### 4.2.1 文档卡片 (DocumentCard)
- 文档基本信息展示
- 快捷操作按钮
- 标签显示

#### 4.2.2 用户头像 (UserAvatar)
- 头像显示
- 用户名展示
- 在线状态指示

## 5. 交互设计

### 5.1 操作反馈
- **成功操作**: 绿色提示信息
- **错误操作**: 红色错误信息
- **警告信息**: 橙色警告提示
- **加载状态**: 加载动画和骨架屏

### 5.2 确认机制
- **删除操作**: 二次确认弹窗
- **批量操作**: 确认选择数量
- **重要修改**: 密码确认

### 5.3 快捷操作
- **键盘快捷键**: Ctrl+S保存，Esc取消等
- **右键菜单**: 文档列表右键操作
- **批量选择**: Shift+点击连续选择

## 6. 错误页面设计

### 6.1 404页面
- 友好的错误提示
- 返回首页链接
- 搜索建议

### 6.2 403权限错误页面
- 权限不足提示
- 联系管理员信息

### 6.3 500服务器错误页面
- 服务器错误提示
- 刷新重试按钮

## 7. 移动端适配
